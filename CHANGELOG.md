# Changelog

## Unreleased

- `hayaid`, `hayai-rpc`: the JSON-RPC server has the cookie authentication of Zakura and zcashd, on by default. The node writes `__cookie__:<secret>` to `.cookie` in `[rpc] cookie_dir` (default `[state] data_dir`, mode 0600) at each start and removes the file at a clean stop. Each request needs `Authorization: Basic` with the content of the file (`curl -u "$(cat hayaid-data/.cookie)"`), or gets the HTTP status 401. `[rpc] enable_cookie_auth = false` turns it off. A client without the credentials no longer works. `hayai_rpc::Cookie`, `hayai_rpc::cookie::authorization`, `HttpServer::serve` takes the cookie, `Node::rpc_cookie`. `docs/hayaid.md`, Protection of the port.
- `hayai-rpc`: the request line and the headers of one HTTP request have a limit of 16 KiB together (`http::MAX_HEAD`, status 431), on the RPC server and on the metrics server.
- `hayaid`: `[mining] lane_publication` = `all` (default), `public` or `none`: what a mining node publishes of its template to its hayai peers before it finds a block. With `none` the node sends no batch and no candidate of its own template. The block still goes out over the compact relay. The lanes of other miners do not depend on the key.
- `hayaid`, `hayai-rpc`: method `sendprivatetransaction` (a node with `lane_publication` `public` or `none`): the transaction is in the mempool and in the template, and the node does not announce it and does not give it to a peer before a block contains it. `Node::submit_private_tx`, `Mempool::admit_private`, `Mempool::is_private`, `mempool::PublicTxs`.
- `hayai-rpc`, `hayaid`: methods `getinfo`, `getmininginfo`, `getblocksubsidy`, `getnetworksolps`, `getnetworkhashps`, `getdifficulty`, `getnetworkinfo`, `getpeerinfo`, `getmempoolinfo`, `getblockheader`, `getblock` with verbosity 1 (the default verbosity, was an error), `getchaintips`, `validateaddress`, `z_validateaddress`, `addnode` and `stop` (Regtest only), `ping`, `getbestblockheightandhash`, `getdeprecationinfo`, with the fields of Zakura. Table of the differences: `docs/hayaid.md`, JSON-RPC server. `getblockhash 0` has the hash of the genesis block (was error -8).
- `hayai-rpc`: `NodeQuery` has `block_info`, `header_context`, `chain_tips`, `node_state`, `peers`, `mempool_size`, `add_node`, `ping`, `stop`, and `send_transaction` takes `private`. Types `BlockInfo`, `BlockState`, `ChainTip`, `NodeState`, `PeerRow`, `Pools`.

The lowest fee of a transaction is 800 zatoshis (was 10,000). Table: `docs/mempool-policy.md`.
